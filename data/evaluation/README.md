# Evaluation Set — Usage and Rules

This directory contains the **sealed independent evaluation set** used to
benchmark guardrail model performance at each training stage.

## Rules

1. **Never use this data during training or DPO preference mining.**
   It exists solely to grade model checkpoints. Treat it as a sealed exam.

2. **Generated by a different teacher model than the training data.**
   Training data: `gemini-1.5-pro`. Evaluation data: `claude-3-5-sonnet`.
   Using the same teacher for both introduces circular evaluation — the
   student is graded on the same rubric it was optimized to satisfy.

3. **Human review is mandatory before sealing.**
   Generate 300–500 examples, review every one manually, then lock the file.
   Once sealed, no additions or modifications are permitted.

4. **This directory is committed to git** (unlike `data/generated/`).
   The eval set is version-controlled so that all benchmark runs are
   reproducible against the exact same examples.

## File

| File | Description |
|---|---|
| `eval_independent.jsonl` | Sealed eval set — 300–500 examples across all 5 difficulty tiers and all mask types |

## Format

Each line is a JSON object matching the guardrail output schema:

```json
{
  "text":         "<raw user input>",
  "decision":     "ALLOW | BLOCK | SANITIZE",
  "category":     "<taxonomy category>",
  "risk_level":   "low | medium | high",
  "confidence":   0.0,
  "masked_input": "<input with [MASKED_*] tokens>",
  "mask_spans":   [{"token_start": 0, "token_end": 1, "type": "NAME", "original": "..."}],
  "tier":         "obvious | ambiguous | dual_use | adversarial | borderline"
}
```

## How to Generate

Use `scripts/generate_data.py` with `--model claude-3-5-sonnet-20241022`
and write to this directory. Then run `scripts/validate_dataset.py` with
`--with-spans` before sealing.

```bash
uv run scripts/generate_data.py \
    --n 400 \
    --model claude-3-5-sonnet-20241022 \
    --output data/evaluation/eval_independent.jsonl \
    --validate

uv run scripts/validate_dataset.py \
    --input data/evaluation/eval_independent.jsonl \
    --with-spans
```

After both commands pass, commit `eval_independent.jsonl` and do not modify it again.
